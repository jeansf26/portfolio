## 🚀 Como Executar

Por ser uma aplicação estática construída com tecnologias web nativas (HTML5, CSS3 e JavaScript puro), basta abrir o arquivo `index.html` em qualquer navegador.

Se preferir utilizar um servidor local:
```bash
# Com Python 3
python -m http.server 3000

# Ou com extensões como Live Server no VS Code
```
Acesse `http://localhost:3000` no seu navegador.
